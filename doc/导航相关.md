# G1 导航系统部署指南

## 前提条件

机器人上需要预装以下 ROS 工作空间：

| 组件 | 工作空间路径 | 说明 |
|------|-------------|------|
| Super-LIO | `~/Super-LIO/devel_isolated/setup.bash` | LiDAR 惯性里程计，提供重定位（发布 `/lio/robo/odom` 和 `/lio/cloud_world`） |
| Livox 驱动 | `~/livox_ws/devel/setup.bash` | MID360 LiDAR 驱动（`livox_ros_driver2`） |
| ROS Noetic | `/opt/ros/noetic/setup.bash` | 基础 ROS 环境 |
| 2D 地图 | Super-LIO 包内 `map/exhibit_2d_map.yaml` | 预先建好的 2D 栅格地图，供 `map_server` 加载 |

> 以上组件由 `navigation_manager` 自动调用，无需手动启动。
> 需要准备一个扫描地图的2D平面地图：将Super-LIO扫描得到的map.pcd按照z轴 (-1.3m到0.5m)映射到xy平面，得到pgm格式的图片，用图片修理工具修处轮廓清晰的地图。（有困难可以找广州这边协助）
> “终端 B — 执行任务” 需要使用部署环境的真实点位（放入config/routes/里面），测试时，若重定位成功后可以使用ros的命令查看当前位置是一个xy二维点。

## 1. 同步代码到机器人

在开发机（自己的笔记本）上执行：

```bash
rsync -avz --delete /home/lemon/vscode_projects/g1_base/ unitree@192.168.10.99:/home/unitree/g1_navigation/
```

## 2. 启动导航（机器人上操作）

### 终端 A — 底层导航栈

```bash
bash ~/g1_navigation/start_navigation_manager.sh
```

`navigation_manager` 会自动按顺序启动：

1. **roscore**（如果尚未运行，自动拉起）
2. **Super-LIO 重定位** — `roslaunch super_lio relocation.launch`
3. **MID360 驱动** — `roslaunch livox_ros_driver2 msg_MID360.launch`
4. 等待 `/lio/cloud_world` 和 `/lio/robo/odom` topic 有数据（超时 60s）
5. **odom_to_tf + move_base 导航栈** — `start_navigation.sh`
6. 等待 `/odom_2d` + TF (`map->base_link`) + move_base action server 就绪

全部就绪后状态变为 `READY`，发布到 `/navigation_manager/ready`。

### 终端 B — 执行任务

```bash
source ~/Super-LIO/devel_isolated/setup.bash
export ROS_MASTER_URI=http://192.168.10.99:11311
export ROS_IP=192.168.10.99
python3 ~/g1_navigation/scripts/nav_script.py eth0 ~/g1_navigation/config/routes/waypoint_1.yaml
```

将 `waypoint_1.yaml` 替换为实际路线文件（可选：`waypoint_2.yaml`、`waypoint_3.yaml`）。


## 3. 底层启动架构

```
navigation_manager.py (--auto-ensure)
  |
  |-- start_pc2_localization.sh
  |     |-- roslaunch super_lio relocation.launch    --> /lio/robo/odom, /lio/cloud_world
  |     |-- roslaunch livox_ros_driver2 msg_MID360.launch  --> MID360 点云
  |
  |-- start_navigation.sh
        |-- odom_to_tf.py       --> TF (world->base_link) + /odom_2d
        |-- roslaunch g1_navigation.launch
              |-- map_server                --> /map
              |-- static TF (map->world)
              |-- pointcloud_to_laserscan   --> /scan (从 /lio/cloud_world 转换)
              |-- move_base (TEB planner)   --> /cmd_vel
```
